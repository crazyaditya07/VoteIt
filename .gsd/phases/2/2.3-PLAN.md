## Objective
Connect the React UI to the Sepolia smart contract instance to display proposal information seamlessly, execute reliable transaction calls, and handle web3 loading/error states.

- .gsd/SPEC.md

## Success Criteria
- [ ] Deployed contract's data is accurately queried and rendered in the UI.
- [ ] Transactions can be submitted mapping option indices securely.
- [ ] Post-vote behavior clearly blocks duplicate attempts without raw console errors (User sees "Already Voted" text natively).
- [ ] Smooth transition handling states exclusively through Wagmi's built-in transaction status hooks.
