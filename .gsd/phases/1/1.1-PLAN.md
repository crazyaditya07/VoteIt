# Plan 1.1: Hardhat Setup & Smart Contract Development

## Objective
Initialize the Hardhat environment with TypeScript and create the core single-proposal voting smart contract.

## Context
- .gsd/SPEC.md
- .gsd/DECISIONS.md (Phase 1 Decisions)

## Tasks

<task type="auto">
  <name>Initialize Hardhat Project</name>
  <files>
    - hardhat.config.ts
    - package.json
  </files>
  <action>
    - Initialize a new Node.js project.
    - Install `hardhat`, `@nomicfoundation/hardhat-toolbox`, and TypeScript dependencies.
    - Configure `hardhat.config.ts` to include the Sepolia network setting (reading URLs and Private Keys from environment variables using `dotenv`).
    - Explicitly avoid installing frontend dependencies yet (Phase 2 scope).
  </action>
  <verify>npx hardhat compile</verify>
  <done>Hardhat project successfully initializes and compiles an empty project without configuration errors.</done>
</task>

<task type="auto">
  <name>Implement Voting Smart Contract</name>
  <files>
    - contracts/Voting.sol
  </files>
  <action>
    - Create a Solidity contract `Voting.sol` (pragma >=0.8.0).
    - Implement a dynamic constructor taking `string title`, `string description`, and `string[] options`.
    - Enforce "1 wallet = 1 vote" mapping utilizing `msg.sender`.
    - Provide a robust voting function that checks if the sender hasn't voted and valid option constraints.
    - Implement `VoteCast` event emission.
    - Do NOT store any PII (names/emails) on chain.
  </action>
  <verify>npx hardhat compile</verify>
  <done>The `Voting.sol` contract compiles cleanly via Hardhat with zero compilation warnings.</done>
</task>
