# Plan 5.2: Node.js Backend Setup & Web2 Authentication

## Objective
Abstract user personal data away from the DApp layer by constructing a secure Node.js backend acting independently as an authentication layer before permitting poll interaction.

## Context
- backend/package.json
- backend/src/server.ts
- backend/src/models/User.ts
- backend/src/models/PollMeta.ts
- backend/src/middleware/auth.ts
